# DARWIN-Ω console

Static dashboard for the DARWIN swarm: LLM lane health and finding-triage panel.

No build step, no dependencies, no backend of its own. It paints from an embedded
snapshot and upgrades to live data if the Render node answers. A dashboard that
shows "error" when its backend is down tells you nothing exactly when you need it.

Live: https://ryder777777.github.io/darwin-console/
